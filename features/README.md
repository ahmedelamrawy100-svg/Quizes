### 2. تعديل كل كارت كويز في `index.html`

أضف `data-quiz-key` على كل كارت. مثال:
```html
<a href="Annabelle Quiz.html" class="quiz-card" data-quiz-key="annabelle" style="background-image: url('pic/Annabelle.jpg');">
  <h2 class="card-title">Annabelle</h2>
</a>
